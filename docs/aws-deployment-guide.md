# ShiftShield: AWS SAM Deployment Guide

**Owner**: Gufran (Cloud & Product)  
**Target AWS Region**: `ap-south-1` (Mumbai)  
**Stack Name**: `shiftshield-prod` (or `shiftshield-dev`)

---

## 1. Prerequisites

1. **AWS CLI & SAM CLI**:
   - `aws --version` (installed and configured)
   - `sam --version` (SAM CLI installed)
2. **Credentials & Permissions**:
   - Run `aws sts get-caller-identity` to confirm active admin role/credentials.
   - Target region: `ap-south-1`.
3. **Python 3.12**:
   - Ensure Python 3.12 is active.
4. **AWS Budget Safeguard**:
   - Before deploying, create an AWS Budget with an email alert at \$5.00 USD to prevent unexpected billing.

---

## 2. Infrastructure Architecture

The deployment is managed by [`template.yaml`](../template.yaml) and creates:
- **API Gateway (HTTP API v2)**: Proxies all `/api/*` and root routes to the API Lambda with CORS.
- **FastAPI / Mangum Lambda (`ApiFunction`)**: Handles site creation, forecast calculation, anonymous rest verification, and rulebook approvals.
- **Scheduled Evaluator Lambda (`EvaluatorFunction`)**: Runs every 15 minutes to evaluate heat conditions and schedule alerts.
- **EventBridge Scheduler (`FifteenMinuteSchedule`)**: Invocations every 15 minutes with Dead Letter Queue (`EvaluatorDeadLetterQueue`).
- **9 DynamoDB Tables** (`PAY_PER_REQUEST`):
  1. `shiftshield-prod-sites`
  2. `shiftshield-prod-site-state`
  3. `shiftshield-prod-alert-keys` (with 48h TTL)
  4. `shiftshield-prod-issue-log`
  5. `shiftshield-prod-acks`
  6. `shiftshield-prod-rest-confirms`
  7. `shiftshield-prod-rulebooks`
  8. `shiftshield-prod-obligation-log`
  9. `shiftshield-prod-replay-runs`
- **AWS SNS Topic**: `shiftshield-prod-alerts` for email-based alert notifications.
- **Secrets Manager**: `shiftshield-prod-ack-signing-secret` for HMAC-SHA256 supervisor token signatures.
- **CloudWatch Alarms**: Tracks unhandled Lambda exceptions.

## 3. Deployment Steps

### Step 1: Validate SAM Template
```bash
sam validate --lint
```

### Step 2: Build the Serverless Application
Build inside a container to compile native C-extensions (such as `pywbgt`, `numpy`, `metpy`) matching the AWS Lambda execution environment:
```bash
sam build --use-container
```

### Step 3: Deploy to AWS
For first-time deployment with guided interactive prompts:
```bash
sam deploy --guided
```
Prompt responses:
- **Stack Name**: `shiftshield-prod`
- **AWS Region**: `ap-south-1`
- **Parameter Environment**: `prod`
- **Parameter AppMode**: `demo` (or `field` after safety sign-off)
- **Confirm changes before deploy**: `Y`
- **Allow SAM CLI IAM role creation**: `Y`
- **Disable rollback**: `N`

For subsequent automated deployments:
```bash
sam deploy --no-confirm-changeset
```

### Step 4: Verify Deployment Outputs
Upon successful deployment, SAM outputs the endpoints:
- `HttpApiUrl`: The public API Gateway URL (e.g. `https://xxxxxx.execute-api.ap-south-1.amazonaws.com`).
- `AlertTopicArn`: SNS topic ARN for alert subscriptions.

---

## 4. Frontend Deployment (AWS Amplify or S3 + CloudFront)

1. Build the production React assets:
   ```bash
   pnpm --dir frontend run build
   ```
2. Set the `VITE_API_URL` environment variable to the `HttpApiUrl` generated by SAM.
3. Deploy the `frontend/dist/` output directory to AWS Amplify Hosting or an S3 bucket configured with CloudFront.

## 5. Local Development vs. Cloud Deployment

| Feature | Local Dev Mode | AWS Cloud Production |
|---|---|---|
| **Storage** | SQLite (`/tmp/shiftshield-local.sqlite3`) | AWS DynamoDB (9 on-demand tables) |
| **Alerts** | In-app notification / Mailbox preview | AWS SNS email delivery |
| **Schedule** | Local background loop / test triggers | Amazon EventBridge Scheduler (15 min) |
| **Token Secret** | Ephemeral URL-safe token | AWS Secrets Manager (48-char random) |
| **Bedrock** | Mock / Local parser fallback | Amazon Bedrock (`bedrock:InvokeModel`) |
